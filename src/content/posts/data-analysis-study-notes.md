本文是公务员考试《行政职业能力测验》**资料分析**模块的学习笔记整理。资料分析是行测中"客观性最强、最可通过练习稳定拿分"的模块，理解下面的基础概念是解题的必要前提。

## 一、资料分析是什么

资料分析测查应考人员对各种形式的统计资料（文字、图形、表格等）进行正确理解、分析、计算、比较、处理的能力。

核心特点：

- **材料形式**：全部采用真实官方公开数据，以文字、表格、柱状图、折线图、饼状图等统计资料为载体，内容涉及经济、社会、人口、贸易等领域。
- **题目数量**：1 篇材料通常对应 5 道题目；国考统一考察 4 篇材料共 20 题；各省省考题量不统一（15 或 20 题为主）；事业单位考试以 10 或 15 道为主，部分地区出现过 5 道的情况。
- **核心能力**：快速定位数据、识别考点、运用公式、估算取舍。

> 相对数量关系，资料分析对数学思维和解题技巧要求更低、题型更少、公式有限；相对言语理解和判断推理，客观性更强；相对政治理论和常识，复习范围更可控。**资料分析是公考必须突破的模块。**

## 二、基期与现期

基期和现期不会直接出现在题目材料里，但理解二者关系是解题的必要前提。

- **基期**：比较两个时期变化时用来做比较值（基准值）的时期，数值通常作为计算过程中的除数或减数。
- **现期**：相对于基期，当前所处的时期，数值通常作为被除数或被减数。

> **※ 与谁相比，谁为基期。**

在"最值"比较题中，常出现"增加（长）最多"和"增加（长）最快"的问法：前者（多少）比较的是**增长量**，后者（快慢）比较的是**增长率**。

## 三、增长量与增长率

- **增长量**：现期与基期之间的绝对差值，是**绝对量**。
- **增长率**（又称增长速度、增长幅度、增速）：现期与基期之间的相对差异，是**相对量**。

一般情况下，"增长率"≡"增长速度"≡"增长幅度"。

> **※ 增长了 2.5 倍 = 增长率为 250%**，即 1 倍 = 100%。

其他注意点：

- 若问"变化幅度最大"，看增速**绝对值**大小；若问"增长幅度最大"，看增速**实际**大小。

## 四、比重、比值、平均数、倍数

| 术语             | 含义                    | 公式与要点                                                                                                          |
| ---------------- | ----------------------- | ------------------------------------------------------------------------------------------------------------------- |
| **比重**   | 某事物在整体中所占分量  | 比重 = 部分 / 整体 × 100%；各部分比重和为 100%；A、B 两部分时，A 提升的比重 = B 下降的比重；题干出现"占"字即考比重 |
| **比值**   | 两数相比所得数值        | 一般比较值                                                                                                          |
| **平均数** | 总量分成若干份          | "均"前、"每/平均每"后用做分母（均前每后做分母）                                                                     |
| **倍数**   | 对比基数抽象为 1 的数值 | A 比 B 多多少倍 = A 是 B 的多少倍 − 1                                                                              |

平均数的"均前每后做分母"举例：

- 人均消费：人数（均前）做分母 → 人均消费 = 总消费 / 总人数
- 平均每月进口量：月（平均每后）做分母 → 平均每月进口量 = 总进口量 / 总月份数

倍数举例：

- 城镇是农村的多少倍 = 城镇 / 农村
- 城镇比农村多多少倍 = 城镇 / 农村 − 1

## 五、常见统计术语

### 同比与环比

- **同比**：以上年同期为基期比较。如 2023 年 12 月与 2022 年 12 月相比。
- **环比**：与上一个相邻统计周期比较。如 2023 年 12 月与 2023 年 11 月相比（2023 年 1 月与 2022 年 12 月相比也算环比）。

### 百分数与百分点

- **百分数**：用 "%" 表示，通过数值相除得到。用于（1）部分在整体中所占比重；（2）某指标的增长率。
- **百分点**：一个差值，通过百分数相减得到。用于两个以百分数表示的数值（如两个增长率、两个比重）的差值。

示例：2024 年男毕业生比重 52%，2023 年 48%，则 2024 年比重**上升 4 个百分点**。若 2024 年人数增长率 12%，增速较上年放缓 3 个百分点，则 2023 年增速为 15%。

增速变化的几种表述（设今年增长率为 10% / -10%）：

| 表述                                      | 去年增速 |
| ----------------------------------------- | -------- |
| 增长 10%，增幅扩大（上升/回升）5 个百分点 | 5%       |
| 增长 10%，增幅缩小（下降/回落）5 个百分点 | 15%      |
| 增长 -10%，增速扩大 5 个百分点            | -15%     |
| 增长 -10%，增速缩小 5 个百分点            | -5%      |
| 增长 -10%，降幅扩大 5 个百分点            | -5%      |
| 增长 -10%，降幅收窄 5 个百分点            | -15%     |

### 翻番、成数、指数

- **翻番**：数量加倍，翻一番 = 原来的 2 倍。公式：现期 / 基期 = 2ⁿ，即翻了 n 番。
- **成数**：一成为总量的 10%，二成为 20%，以此类推。
- **指数**：以基期数值为 100，其他时期与基期相比得到的相对值。指数 = 报告期 / 基期 × 100。**同比增长率 =（指数 − 100）%**。

### 地区划分（按经济政策）

| 地区 | 包含省份（简称/全称）                                                                                       |
| ---- | ---------------------------------------------------------------------------------------------------------- |
| 东部 | 京（北京）、津（天津）、冀（河北）、沪（上海）、苏（江苏）、浙（浙江）、闽（福建）、鲁（山东）、粤（广东）、琼（海南） |
| 中部 | 晋（山西）、皖（安徽）、赣（江西）、豫（河南）、鄂（湖北）、湘（湖南）                                         |
| 西部 | 内蒙古（内蒙古自治区）、桂（广西）、渝（重庆）、川（四川）、黔（贵州）、滇（云南）、藏（西藏）、陕（陕西）、甘（甘肃）、青（青海）、宁（宁夏）、新（新疆） |
| 东北 | 辽（辽宁）、吉（吉林）、黑（黑龙江）                                                                         |

> **※** 部分材料按三个地区划分时，辽宁归东部，吉林、黑龙江归中部。

### 生产总值与三大产业

- **产业增加值**：该行业在周期内比上个清算周期的增长值（现期量，切忌与增长量混淆）。
- **GDP**：一定时期内一国生产的全部最终产品和劳务价值，是三大产业增加值之和；地区对应称"地区生产总值"。
- **三大产业**：
  - 第一产业：农、林、牧、渔业等（提供生产资料）。
  - 第二产业：采矿业，制造业，电力、煤气及水的生产和供应业，建筑业（加工产业）。
  - 第三产业：除一、二产业外的其他行业（交通仓储邮政、信息技术、批零、住宿餐饮、金融、房地产、教科文卫等）。

### 资产与利润相关

| 指标               | 公式                                                   |
| ------------------ | ------------------------------------------------------ |
| 资产负债率         | 总负债 / 总资产 × 100%                                |
| 总资产利润率       | 总利润 / 总资产 × 100%                                |
| 产销率             | 销售数量 / 生产数量 × 100%                            |
| 主营业务收入利润率 | 主营业务利润 / 主营业务收入 × 100%                    |
| 毛利率             | （主营业务收入 − 主营业务成本）/ 主营业务收入 × 100% |

> **※** 资料分析中利润率默认除以**收入**；数量关系中利润率一般指**成本利润率**（利润 / 成本）。

### 进出口相关

- 贸易顺差 = 出口额 − 进口额（出口 > 进口）
- 贸易逆差 = 进口额 − 出口额（进口 > 出口）
- 贸易总额 = 进出口总额 = 进口额 + 出口额

### 居民可支配收入

- 按来源：工资性收入、经营净收入、财产净收入、转移净收入。
- 按地区：城镇居民可支配收入、农村居民可支配收入。

### 财政总收入与五年规划

- 财政总收入 = 一般公共预算收入 + 政府性基金收入 + 国有资本经营收入 + 社保基金收入；其中一般公共预算收入 = 税收收入 + 非税收收入。
- 五年规划（常考时间段）：十一五（2006–2010）、十二五（2011–2015）、十三五（2016–2020）、十四五（2021–2025）、十五五（2026–2030）。

### 名义增长率与实际增长率

- **名义增长率**：未扣除价格因素的增长率。
- **实际增长率**（按可比价格计算）：扣除价格因素后的增长率。
- 关系：**名义增长率 = 实际增长率 + CPI 增长率 + 实际增长率 × CPI 增长率 ≈ 实际增长率 + CPI 增长率**。

> **※** 若名义增长率 > 实际增长率，则物价上涨。

### 人口相关

| 指标           | 公式                                                            |
| -------------- | --------------------------------------------------------------- |
| 自然增长人数   | 出生人口数 − 死亡人口数                                        |
| 人口出生率     | 年出生人口数 / 年平均人口数 × 1000‰                           |
| 人口死亡率     | 年死亡人口数 / 年平均人口数 × 1000‰                           |
| 人口自然增长率 | （年出生 − 年死亡）/ 年平均人口数 × 1000‰ = 出生率 − 死亡率 |
| 抚养比         | （0–14 岁 + 65 岁及以上）/ 15–64 岁劳动年龄人口 × 100%       |
| 老年人口抚养比 | 65 岁及以上 / 15–64 岁 × 100%                                 |
| 少年儿童抚养比 | 0–14 岁 / 15–64 岁 × 100%                                    |

> 年平均人口数 =（年初人口数 + 年末人口数）/ 2。

### 货物周转量与旅客周转量

- 货物周转量 = 货物运输量 × 运输距离（单位"吨公里"）
- 旅客周转量 = 旅客人数 × 运输距离（单位"人公里"）

### 增长贡献率、拉动增长率、发展速度

| 指标       | 公式                        | 含义                                 |
| ---------- | --------------------------- | ------------------------------------ |
| 增长贡献率 | 部分增量 / 整体增量 × 100% | 某部分增量占总体增量的比重           |
| 拉动增长率 | 部分增量 / 整体基期 × 100% | 某部分增长量拉动整体增长多少个百分点 |
| 发展速度   | 现期 / 基期 = 1 + 增长率    | 反映现象发展变动程度                 |

### 城镇化率、互联网普及率与 R&D

- 城镇化率 = 城镇人口 / 总人口 × 100%
- 互联网普及率 = 网民规模 / 人口总规模 × 100%
- R&D 经费投入强度 = R&D 经费 / 生产总值
- R&D 活动特征：新颖性、创造性、不确定性、系统性、可复制性

### 恩格尔系数

恩格尔系数 = 食品支出总额 / 个人消费支出总额。系数越高，生活水平越低。

## 六、ABRX 字母体系（基础四量）

花生老师习惯用 **ABRX** 表示资料分析最基础的四个量：

- **A** —— 基期
- **B** —— 现期
- **X** —— 增长量
- **R** —— 增长率

四量之间存在"**知二求二**"的关系：

| 已知               | 求增长量 X     | 求增长率 R                  | 求另一量             |
| ------------------ | -------------- | --------------------------- | -------------------- |
| 基期 A、现期 B     | X = B − A     | R = (B − A) / A = B/A − 1 | —                   |
| 基期 A、增长量 X   | —             | R = X / A                   | B = A + X            |
| 现期 B、增长量 X   | —             | R = X / (B − X)            | A = B − X           |
| 现期 B、增长率 R   | X = B/(1+R)·R | —                          | A = B / (1 + R)      |
| 基期 A、增长率 R   | X = AR         | —                          | B = A(1 + R)         |
| 增长量 X、增长率 R | —             | —                          | A = X/R，B = X/R + X |

举例：去年体重 80 千克，今年涨到 90 千克 → A=80，B=90，X=10，R=10/80=12.5%。
