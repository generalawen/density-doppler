本文是学习马克思主义基本原理笔记整理，涵盖核心知识点、易混淆点及真题解题思路。

## 一、《共产党宣言》与陈望道翻译

- **《共产党宣言》的地位**：1848 年马克思和恩格斯发表《共产党宣言》，标志着马克思主义的公开问世，同时也标志着社会主义的公开问世。
- **陈望道的贡献**：1920 年陈望道将《共产党宣言》翻译成中文，为马克思主义在中国的传播奠定了思想基础，次年（1921 年）中国共产党正式成立。
- **真理的味道是香甜的**：习近平总书记曾引用陈望道蘸墨水吃粽子的故事，说明追求真理过程中的专注与投入。

## 二、马克思主义理论的三大组成部分与直接理论来源

### 三大组成部分

马克思主义基本原理包含三个部分：

1. **马克思主义哲学**（马哲）
2. **马克思主义政治经济学**（马正经）
3. **科学社会主义**

### 直接理论来源（一一对应）

| 组成部分             | 直接理论来源           |
| -------------------- | ---------------------- |
| 马克思主义哲学       | 德国古典哲学           |
| 马克思主义政治经济学 | 英国古典政治经济学     |
| 科学社会主义         | 英法两国的空想社会主义 |

> **重点补充**：德国古典哲学包含两个重要组成部分——**黑格尔的辩证法**和**费尔巴哈的唯物主义**。注意，马克思是"吸收"了黑格尔的辩证法精神，而非"创立"了辩证法。如果题目说"马克思创立了辩证法"，该说法是错误的。

## 三、马克思主义的鲜明特征

| 特征             | 核心内涵                                                                         |
| ---------------- | -------------------------------------------------------------------------------- |
| **科学性** | 理论是正确的，是我们党的根本指导思想                                             |
| **革命性** | 为无产阶级革命提供理论指导，具有辩证法的批判精神                                 |
| **实践性** | **首要的基本的观点**——从实践中来，到实践中去，由实践检验其正确性         |
| **人民性** | 人民至上的政治立场，人民群众是历史的创造者                                       |
| **发展性** | 与时俱进，能与不同国情结合产生新观念（如毛泽东思想、中国特色社会主义理论体系等） |

> **两大发现**：**唯物史观和剩余价值学说是马克思一生最伟大的两个发现，是马克思独创的思想。**

## 四、哲学的含义与两对关系

### 世界观与方法论的关系

- **世界观决定方法论**：有什么样的世界观，就会采取什么样的方法解决问题。
- **方法论体现世界观**：按某种方法解决问题，背后也体现了相应的世界观。

### 具体科学与哲学的关系

- 具体科学是哲学的基础，哲学是对具体科学的概括和总结。
- 哲学反过来为具体科学提供世界观和方法论的指导。

> **易错点**：具体科学和哲学**不是整体与部分的关系**，而是**共性与个性（一般与特殊）** 的关系。不能说"哲学是具体科学的汇总"。

> **另一个易错点**：哲学思想并不一定都是正确的，例如唯心主义观点就有问题。

## 五、哲学的基本问题与派别划分

### 哲学的基本问题

哲学的基本问题是**物质和意识（思维与存在）的关系问题**，包括两个方面：

1. **第一性问题**（世界本源）：谁是第一性？物质还是意识？——这是区分唯物主义与唯心主义的唯一标准。
2. **同一性问题**（世界是否可知）：意识能否认识物质？——区分可知论与不可知论。

### 唯物主义的发展形态

| 形态                                     | 对物质的理解                                   | 特点与局限                                                                                                                                                           |
| ---------------------------------------- | ---------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **古代朴素唯物主义**               | 某种具体的实物（金木水火土、阴阳二气、元气等） | 根本上承认物质是本源，正确；但将物质归结为具体实物，有局限性                                                                                                         |
| **近代形而上学唯物主义**           | 原子                                           | 三大缺陷：**机械性**（认为所有运动都是机械运动）、**形而上学性**（孤立、片面、静止）、**不彻底性**（自然观唯物、历史观唯心，又称"半截子唯物主义"） |
| **现代唯物主义（马克思主义哲学）** | 物质的本质属性是**客观实在性**           | 不将物质归结为具体实物或原子，而是抽象出"客观实在性"这一本质属性                                                                                                     |

> 近代形而上学唯物主义又称**机械唯物主义**（因机械性得名）或**半截子唯物主义**（因不彻底性得名）。

### 唯心主义的两种形式

| 类型                   | 核心观点                         | 常见关键词/案例                                                        |
| ---------------------- | -------------------------------- | ---------------------------------------------------------------------- |
| **主观唯心主义** | 人的主观精神决定世界上的一切     | "我思故我在"、"人是万物的尺度"、"心外无物"、"仁者心动"、"万物皆备于我" |
| **客观唯心主义** | 独立于人之外的客观精神是宇宙本源 | 上帝创世纪、存天理灭人欲、道生万物、绝对精神                           |

## 六、真题解题技巧与易错点

### 理论来源的易混淆点

- **创立与吸收的区别**：马克思并没有创立辩证法，而是吸收了黑格尔的辩证法精神。
- **来源与基础的区别**：科学社会主义的**理论来源**是空想社会主义，但它的**理论基础**是唯物史观和剩余价值学说。题目中措辞不同，答案不同。

### 多选题策略

国考政治理论的多选题通常不会设置过多陷阱。对 26 年联考的分析显示：23 道"选几项"题中，15 道只挖了一个坑，6 道根本没挖坑，仅 2 道挖了两个坑。遇到不会的题，优先考虑"只有一个错误选项"或"全对"的情况。
